🎤 RiffLens

Drop any .wav file and see what it actually contains: every RIFF chunk with sizes and offsets, the real format details (PCM 8/16/24/32-bit, IEEE float, extensible), per-channel peak, RMS, DC offset and clipping, LIST INFO metadata, cue points, and a waveform drawn from the decoded samples. Hand-rolled parser, no libraries, nothing leaves your browser.

  • Full RIFF chunk walk with pad-byte and truncation handling
  • PCM 8/16/24/32 and float 32/64 sample decoding
  • Clipping detection and per-channel statistics
  • Synthesized demo tones built in-page, then parsed
  • 209 automated checks against an independent Python oracle, cross-checked with Python's wave module
